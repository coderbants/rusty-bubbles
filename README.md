# Charming Bubbles (`charming-bubbles`)

**Charming Bubbles** is a cleanroom Rust port of [Bubbles](https://github.com/charmbracelet/bubbles), the library of common UI components for Bubble Tea — text input, text areas, spinners, stopwatches, file pickers, help views, viewports and more. It tracks upstream Go releases on a rolling basis (this port mirrors upstream `v2.1.0`) and is designed to be used with [charming-bubbletea](https://github.com/coderbants/charming-bubbletea) and [charming-lipgloss](https://github.com/coderbants/charming-lipgloss), with the same 1:1 parity goals as the rest of the Charming port family.

## Installation

```sh
cargo add charming-bubbles
```
